# Getting Started with Vite + preact

This project was bootstrapped following https://blog.jhordyess.com/sass-vite-a-guide-for-your-next-workflow with preact.

## HOW TO DEPLOY

```bash
npm run build
npm run deploy
```

## Develop

In the project directory, you can run:

### `npm run dev`

Runs the app in the development mode.

The page will reload when you make changes.\
You may also see any lint errors in the console.

### `npm run preview`

https://vitejs.dev/guide/cli#vite-preview

Locally preview the production build. Do not use this as a production server as it's not designed for it.
